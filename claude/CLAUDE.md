# Shared Codex workflows

Use the same server and isolated GUI instructions as Codex. The imported files
and GUI helpers are installed by this dotfiles repository under `~/.codex/skills/`.

## Server

Apply this workflow when working with a server, deployment, or production issue:

@~/.codex/skills/server/SKILL.md

## Isolated GUI

Apply this workflow to all agent-owned Linux GUI tests, diagnostics, screenshots,
and automation. Keep the user's desktop undisturbed, including for GTK/WebKit
tests that create windows:

@~/.codex/skills/isolated-gui/SKILL.md
